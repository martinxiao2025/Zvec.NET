# 模板集（任务文档 / 执行报告 / 记忆条目）

骨架由脚本生成（`doc --id`），以下为各节的填写要求与完整模板。**本文件是项目可定制模板的唯一来源**。

## 1. 任务文档模板（tasks/records/T########.md）

```markdown
# T20260001 <标题>

> 状态：<状态> ｜ 类型：<类型> ｜ 优先级：<P0-P3> ｜ 执行者：<执行者> ｜ 创建：<yyyy-MM-dd HH:mm>

## 1. 任务内容
（脚本从 Excel 同步生成：描述、编号验收标准列表、关联编号；状态变更时更新首行引用块）

## 2. 分析与设计
（执行者。方案要点；涉及模块与文件清单；子任务拆分及理由；对公共 API 的影响；假设与边界）

## 3. 执行过程
（执行者。执行中实时追加，禁止事后补写）
| 时间 | 动作 | 详情 |
|-------|------|------|
| 11:20 | 定位 | …（文件:行） |
| 11:35 | 修改 | …（做了什么、为什么） |
| 11:50 | 自测 | <命令> → <结果> |

## 4. 审核记录
（审核者只追加、不修改上文；每轮一个小节，格式见 review-checklist.md）

## 5. 结论
（结果摘要 ≤200 字；提交哈希；遗留问题与后续建议）
```

## 2. 执行报告模板（docs/reports/YYYY-MM-DD-Txxxxxxx~Tyyyyyyy-report.md）

文件名：`<日期>-<本轮最小编号>~<本轮最大编号>-report.md`；单任务为 `<日期>-Txxxxxxx-report.md`；同日同范围第 N 轮加 `-N`。

```markdown
# 任务执行报告 <yyyy-MM-dd>

> 范围：T20260001～T20260003 ｜ 筛选：<状态/类型条件> ｜ 报告生成：<HH:mm>

## 1. 统计

（粘贴 `taskexcel.cs stats` 输出；另加本轮完成/阻塞/跳过计数）

## 2. 任务详情

### T20260001 <标题>
- 类型/优先级/执行者 ｜ 状态：已完成
- 结果摘要：<Excel J 列>
- 过程要点：<任务文档 §2/§3 摘录 2-3 行>
- 审核判定：<§4 最后一轮结论，通过/不通过+轮次>
- 验证：<全量测试结果行>
- 提交：`<short hash>` `<commit message>`

（每个任务一节，同上结构）

## 3. 阻塞与跳过
（无则写"本轮无"；有则：编号 ｜ 原因 ｜ 后续建议）

## 4. 附录
- 全量构建/测试输出摘要
- 本轮事件日志（Log 表 R#### 汇总）
```

## 3. 记忆条目模板（.agents/memory/lessons.md）

按时间**倒序**追加（最新在最上）；每条三行体，编号关联任务：

```markdown
## yyyy-MM-dd T######## <主题≤20字>
- **情境**：遇到了什么/要决定什么
- **决策/踩坑**：做了什么选择或错在哪
- **结论**：下次遇到该怎么做的可执行一句话
```

MEMORY.md 索引同步加一行（最新在最上）：

```markdown
- yyyy-MM-dd <主题>（T########）→ lessons.md#yyyy-mm-dd-txxxxxxxx-主题
```

## 4. 首行引用块状态同步

任务状态每次变更（update --status）后，编排者同步更新对应任务文档首行 `> 状态：…`，保持 Excel 与文档一致。

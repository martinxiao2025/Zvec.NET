## 2. 分析与设计

**方案要点**：一次性结构收敛——任务数据并入 docs/（git mv 保历史）、记忆目录更名 memories/ 并收编项目索引（index.md → project-arch.md）、智能体规范源目录化（<name>/{agent.md,config.json}）并改 config 驱动同步、四层规范收敛（templates.md 并入 agent-conduct.md 六、写作规范）、删除汇总报告环节改为轻量收尾、顺带实现 T20260005（install-to 写目标 .gitignore 放行规则）。

**涉及模块与文件**：

- 结构移动（git mv）：`tasks/`→`docs/tasks/`；`.agents/memory/`→`.agents/memories/`；`.agents/index.md`→`.agents/memories/project-arch.md`；`.agents/agents/*.md`→`.agents/agents/<name>/agent.md`；删除 `docs/reports/`（git rm -r）
- 新建占位：`.agents/agents.md`（一行指针）、`.agents/mcp.json`、`.agents/models.json`（无密钥占位）、`.agents/agents/<name>/config.json` ×2、`.agents/tasks/boundary-tests/task.md`（可复用任务定义示例）
- 脚本 3 份：`taskexcel.cs`（xlsxPath/recordsDir 改 docs/tasks；doc 子命令 §1 改一行引用版，token 优化）；`sync-agents.ps1` 重写（删内置 $toolMap，遍历 .agents/agents/*/ 读 agent.md frontmatter + config.json，生成 .zcode 与 .github 两处映射，幂等 + 陈旧清理）；`install-to.ps1`（复制清单 + memories/project-arch 骨架 + 三占位 + 目标 .gitignore 放行规则）；两份 .ps1 保存 UTF-8 带 BOM（lessons.md 教训）

**关键设计**：sync 的智能体名取 agent.md frontmatter（回退目录名），tools 取 config.json（zcode 连接为逗号串、copilot 为 [数组]），model 非空才写入 frontmatter；生成文件头加 AUTO-GENERATED 注释指向规范源；陈旧清理按「目标目录存在但源没有」判定。doc §1 一行引用避免复制描述/验收全文，完整字段由 read --id 提供。

**拆分子任务及理由**：不拆分。结构收敛与所有引用更新强耦合（中间态会导致路径引用断裂、sync/install 互相不一致），一次性原子完成最安全；T20260005 的 install-to 放行规则按任务指示顺带实现（改动集中在同一份 install-to.ps1，单独跑一轮流水线成本大于收益）。
